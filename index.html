宇和 + 治雲 · 2026/06/07–06/13 · 柏林→漢堡（布萊梅/呂貝克/施威林 day trip）

🎫 票券：建議買 Deutschland-Ticket

  • €63/人/月，兩人 €126（六月一張全程通用）
  • ✅ 含全德 RE / RB / U-Bahn / S-Bahn / 公車 / 電車：柏林+漢堡市區、6/11 布萊梅、6/12 全段、6/13 機場 S1
  • ❌ 不含 IC / ICE / EC 長途：6/9 柏林→漢堡（已訂）；6/12 全是 RE 免費、不用搭 IC
  • ⚠️ 訂閱制 → 6/10 前退訂（買了馬上退，當月仍有效），或用「自動取消單月」的轉售 app
  • 👉 兩人各買一張，估省 ~€150

📱 DB Navigator 查火車怎麼用

  1. 裝 DB Navigator app（藍底白字 DB，官方免費）
  2. 起點/終點打站名選總站，例：Hamburg Hbf → Schwerin Hbf
  3. 設日期時間（出發 Abfahrt 或抵達 Ankunft）
  4. 開 Deutschland-Ticket 篩選（或取消勾 ICE/IC）→ 只剩月票免費的班次
  5. 看車種標籤：RE/RB/S = 月票免費；IC/ICE = 另付。點進去看轉乘站/月台
火車確切班次出發前再用 app 對一次（尤其早上漢堡→施威林、施威林→呂貝克要轉車那段）。
